# Epic 4 Retrospective: Recover from State and Artifact Conflicts

## Status

done

## What Changed

- `/bmad-next` now treats `.bmad-stepper/state.yaml` as an index that must be verified against artifacts, frontmatter, task outputs, tests, review results, repair history, and run records before downstream work is selected.
- Conflict detection now classifies blocking state/artifact contradictions and refuses unsafe continuation in both dry-run and execution paths.
- `/bmad-next --reconcile` now defines interactive choices for update state, trust artifacts, rerun step, skip step, and diagnostic, with confirmation required for any mutation.
- Interrupted runs now have explicit resume, restart, abandon, or reconcile choices, and re-entry reuses proven artifacts while retrying only unproven outputs.
- Schemas and templates now support evidence references, conflict records, reconcile decisions, recovery policy, interrupted run status, re-entry notes, and diagnostic/reconcile output paths.

## Review Findings

- Self-review found the Epic 4 surface consistent with project rules: prompt-first, script-light, BMAD as prerequisite, workflow step as the atomic execution unit, artifacts/frontmatter as proof, and state as an index.
- No blocking follow-ups remained after aligning `/bmad-next`, `/bmad-loop`, command reference, examples, README, schemas, templates, story records, and sprint status.
- Residual risk: recovery behavior is still specified rather than executable. JSON syntax validation can check schemas, but real conflict detection and idempotent re-entry depend on future agent adherence or a later runtime.

## Action Items for Epic 5

- Keep config and state templates aligned with the expanded recovery fields introduced in Epic 4.
- Make project-pinned asset update behavior aware of local schema/template edits so recovery records are not overwritten silently.
- Ensure future run audit records preserve reconcile decisions, diagnostics, interrupted-run choices, review/fix history, and evidence references in a maintainable shape.
